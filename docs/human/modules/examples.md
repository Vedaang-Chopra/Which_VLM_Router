# Examples

## What It Does

End-to-end example scripts demonstrating how to use the ARTEMIS router, load balancer, and inference engine. Three sub-directories.

## Key Files

| Directory | What It Does |
|---|---|
| `examples/load_balancer/` | Load balancer usage: capacity config, scheduling decisions, SLA monitoring |
| `examples/router/` | Router usage: checkpoint loading, `route_request`/`route_batch` API calls |
| `examples/ops/` | Operations: Docker commands, deployment scripts, health checks |

## Current Status

**COMPLETE.** All example scripts are functional and serve as the primary "getting started" reference for new users.
